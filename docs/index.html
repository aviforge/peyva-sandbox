Peyva Sandbox
Learn distributed systems by building one.

Build a wallet. Break it. Fix it. Twenty-two times.

peyva is a small payments system: alice sends bob $20, and the money arrives exactly once. You build it one piece at a time, and each piece exists because the chapter before it showed you a failure.

Start with Chapter 0

How a chapter works

  1. Read the concepts and why they matter. About a hundred words.
  2. Copy a prompt into your own AI coding assistant. It writes the code, in the language you chose.
  3. Run it and watch it fail the way the chapter said it would. Then fix it.

There is no finished code to download. That is the point: you prompt for it, run it, and see for yourself.

What you need

  • An AI coding assistant. Claude Code, Codex, Copilot, or any other.
  • A language. Pick one of 7 in Chapter 0 and keep it for the whole book.
  • One laptop. No cloud, no containers, nothing to install to read.
